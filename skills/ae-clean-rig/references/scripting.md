# Scripting pitfalls that break rigs

The operations behind `ae_do` are ExtendScript generated by the server. These are the After Effects scripting behaviours that produce wrong results without producing an error.

## Addressing things

- **Layer indices shift.** They are 1-based and change on add, delete, move and precompose. Prefer unique layer names in `layer` arguments; when you must use an index, re-read `ae_comp_info` after every structural change.
- **Match names beat display names.** Use `["ADBE Transform Group", "ADBE Position"]` rather than `["Transform", "Position"]`, and effect match names such as `"ADBE Gaussian Blur 2"`; localized AE installs rename the display strings.
- **Effect indices move.** Newer AE versions insert properties into effect groups. Address effect properties by match name, and reacquire property references after `effect.add`, `effect.remove` or `effect.move`.
- **Separated dimensions.** When Position is split into X, Y and Z, edit the follower properties (`ADBE Position_0`, `ADBE Position_1`), not the leader.

## Text

- New text layers can inherit the last used character style. After `layer.create_text`, run `text.reset_style` and then `text.set_style` explicitly; verify weight and case in a render.
- Box text: Position is not necessarily the box's top-left corner. Read `boxTextPos` and the anchor point first; with a centred origin the whole layout lands somewhere else.
- `text.set_style` on the whole layer flattens per-range styling and keyed source text. Read the current Source Text first and use `text.set_style_range` when mixed styles must survive.

## Keys and time

- The first keyframe holds backward. A delayed reveal needs a key at the start (value hidden) or a later in-point.
- Frame-aligned times are `frame / comp.frameRate`. Use the comp's real frame duration, not a rounded value.
- Time remap: removing its last key disables the property. When rewriting remap keys, add the new ones before removing the old, and re-check `timeRemapEnabled`.
- Simplifying keys: bound the loop, and verify the key count actually changed.

## Expressions

- Expression language is not ExtendScript. Inside an expression, shape contents are `content("Group 1").content("Rectangle Path 1")`; `property(...)` is script-side only. Using the wrong one yields silent wrong values or an `expressionError`.
- Compute shared values (gaze, phase, progress) once on a controller and reference it, instead of repeating the calculation in many expressions.
- Read `expressionError` after every `expression.set`. A successful set is not a successful evaluation.

## Renders and files

- A frame render can return before the file is complete. Confirm the PNG exists and opens before viewing it.
- `saveFrameToPng` has been observed to skip requested files without an exception. Check every output, and for many frames prefer a short Render Queue movie.
- Render Queue operations should leave other queue items and their flags as they were.

## Transport behaviour

- Every `ae_do` call is one undo group; never open your own in `eval.run` code.
- `batch.run` is one round trip and one undo group, not a transaction. With `stopOnError: true`, inspect `results` on failure to see what applied.
- A `TIMEOUT` after the request was consumed means the script may still have run. Inspect the project before repeating a mutation; a repeat can duplicate layers or double an offset.
- Modal dialogs are suppressed during a call. A dialog that appears anyway (for example a missing-font prompt on `project.open`) blocks all scripting until dismissed in the AE UI.
- Do not run two mutations or a mutation and a render at once against one After Effects; calls are serialized, and a second MCP server process would collide.

## Verify

- Property reads after each structural edit confirm the addresses you are using still point at the intended layer and property.
- Rendered frames, not property values, prove text style, expression results and effect placement.
